# Guides

Each guide walks through one task from start to finish.

<div class="grid cards" markdown>

-   :lucide-git-compare:{ .lg .middle .lg-icon } **Check your changes**

    ---

    Compare your work with the last commit or with `main`, and fix what you made worse.

    [:octicons-arrow-right-24: Check your changes](check-changes.md)

-   :lucide-bot:{ .lg .middle .lg-icon } **Coding agents**

    ---

    Install with an agent, add the Claude Code hook, or give instructions to Codex and others.

    [:octicons-arrow-right-24: Coding agents](coding-agents.md)

-   :lucide-git-pull-request:{ .lg .middle .lg-icon } **Pull requests and CI**

    ---

    Run the check on every pull request with GitHub Actions or any other CI.

    [:octicons-arrow-right-24: Pull requests and CI](ci.md)

-   :lucide-brush-cleaning:{ .lg .middle .lg-icon } **Clean up existing code**

    ---

    Take an inventory, fix the worst code in small steps, and report the progress.

    [:octicons-arrow-right-24: Clean up existing code](clean-up.md)

-   :lucide-layers:{ .lg .middle .lg-icon } **Stored baselines**

    ---

    Save a snapshot of today's results and hold the code to it until someone reviews a change.

    [:octicons-arrow-right-24: Stored baselines](baselines.md)

</div>

!!! tip "Guides in your terminal"
    The CLI has short versions of these guides for the version you installed. Run `lumioguard-cc guide`
    to list them.
